# 🌾 Agro Forte, Futuro Sustentável — Agrinho 2026

> Projeto interativo focado no equilíbrio entre alta produtividade no campo e a preservação do meio ambiente, desenvolvido para o **Programa Agrinho 2026 (Paraná - Subcategoria 3)**.

Este projeto consiste em uma página web institucional e interativa que apresenta os pilares da agricultura sustentável e conta com um **Simulador de Impacto Positivo**, onde o usuário pode visualizar dados econômicos e ambientais gerados por práticas como Plantio Direto, Uso de Drones e Reuso de Água.

---

## 🚀 Funcionalidades

* **Design Responsivo:** Interface adaptada para dispositivos móveis, tablets e computadores.
* **Cards Informativos:** Apresentação clara dos pilares do agro sustentável (Tecnologia, Manejo e Preservação).
* **Simulador Interativo:** Lógica em JavaScript que calcula e exibe em tempo real os benefícios de cada prática agrícola ao clique de um botão.
* **Navegação Suave:** Menu funcional com rolagem suave entre as seções da página.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web puras (Vanilla Web), sem a necessidade de frameworks externos, garantindo leveza e rapidez no carregamento:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização moderna, uso de Flexbox, efeitos de transição (*hover*) e responsividade.
* **JavaScript (ES6):** Manipulação dinâmica do DOM para o funcionamento do simulador.
